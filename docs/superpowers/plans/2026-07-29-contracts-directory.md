# contracts/ Directory Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move Arena's three contract levels — API, behaviour, and design values — under a single `contracts/` directory, with the design level's generated CSS in a `contracts/design-generated/` sibling.

**Architecture:** Three batches, one per level, in the order api → behaviour → design. Each batch does the same five things in the same order: harden that level's gate with a zero guard (test-first, watched failing), `git mv` the files, repoint every site a program follows, sweep that level's prose citations, and close with a full `bun run check` whose printed counts are compared against a recorded baseline. Design goes last because it touches the most surface and because by then the mechanics are proven twice.

**Tech Stack:** Bun (never npm/node for the scripts), `node:test` + `node:assert/strict` for suites, Style Dictionary for token generation, git.

**Spec:** `docs/superpowers/specs/2026-07-29-contracts-directory-design.md`

## Global Constraints

- **English only.** All code, comments, docs and commit messages are in English. The repo was fully translated from Spanish and never regains any.
- **Bun, not npm/node.** `bun run <script>`, `bun test`, `bun scripts/<file>.mjs`.
- **A commit message containing a backtick is written with a quoted here-doc**, never `git commit -m "…"`. A backtick inside a double-quoted shell string opens command substitution and is silently spliced away. Use `git commit -q -F - <<'MSG' … MSG` and verify with `git log -1 --format=%B`.
- **Every move is a `git mv`**, never a copy-and-delete, so history follows the file.
- **Exactly one rename in the whole refactor:** `tokens/src/TYPE-MAP.md` → `contracts/design/README.md`. Every other file keeps its current name, including lowercase stems like `button.json`, `palette.dark.json` and `menu-item.json` — those stems are identifiers (a pattern's stem is the value a binding writes into `"pattern"`; a token source's stem decides the name of the CSS it emits).
- **Never hand-edit a generated file.** `contracts/design-generated/*.css`, `frameworks/*/Tokens.generated.*` and `frameworks/*/Api.generated.*` are regenerated by their builders. Change the builder, then rebuild.
- **`CHANGELOG.md` is never back-edited.** New entries go under `## [Unreleased]`.
- **Past-tense history is left alone.** A clause describing where something *was* stays as written; only present-tense normative citations are rewritten. `check-duplicate-constants.mjs`'s "which was `frameworks/angular/primitives/chart-internals.ts` when this happened" is the model.
- **`bun run check` is a batch-completion gate, not a per-commit toll.** Individual gates are cheap and stay available per commit; the full sweep runs once at the close of each batch.
- **The test command is the one in `testStep()`**, `scripts/check-all.mjs`. Copied here verbatim because a narrowed invocation is indistinguishable from a complete one:
  ```bash
  bun run build:angular-tests && \
  bun test scripts frameworks/react build/angular-test/angular --path-ignore-patterns='**/*.dom.test.jsx' && \
  bun test --preload ./frameworks/react/test/Preload.js '.dom.test.jsx'
  ```
  `bun test scripts` alone never matches `frameworks/`, and vice versa. Do not reconstruct a shorter one.

### Task 3.2: `fetch-fonts.mjs` can regenerate its CSS without the network

`tokens/fonts.css` is generated output whose `url()` values are relative — `../assets/fonts/…`. Moving it into `contracts/design-generated/` makes those `../../assets/fonts/…`, and a generated file is regenerated, never hand-edited. But `fetch-fonts.mjs` regenerates it by downloading every binary from Google Fonts, which makes the move depend on the network and on a third party serving byte-identical files.

The binaries are already committed in `assets/fonts/`. This task separates emitting the CSS from fetching the fonts.

**Files:**
- Modify: `scripts/fetch-fonts.mjs`
- Test: `scripts/fetch-fonts.test.mjs` (create)

**Interfaces:**
- Produces:
  - `export function fontsCss(faces)` → `string`. `faces` is an array of `{ family: string, weight: number, file: string }`, in emission order. Returns the complete file contents including the header and a trailing newline.
  - `export function facesFromDisk(root)` → the same array, derived from `families(root)` filtered against the `.woff2` files present in `assets/fonts/`, in family emission order then ascending weight.

**A weight declared with no binary is skipped, not an error, and this is the load-bearing fact of the task.** `families()` returns the *same* weight list for every family — every `fw-*` token, sorted — but Google Fonts does not serve every weight for every family. The committed tree proves it: `assets/fonts/` holds Archivo at 400–900 (six binaries) and Familjen Grotesk and Spline Sans Mono at 400–700 (four each), and `fonts.css` has exactly those fourteen `@font-face` rules. A `facesFromDisk` that crossed families with weights would demand `familjen-grotesk-800.woff2`, which has never existed. What **is** an error is a family that ends up with no face at all — that is the silent-failure shape `check:fonts` exists to catch, and `fetch-fonts.mjs`'s own header records it happening once.
  - A `--css-only` argv flag on `main()` that calls `facesFromDisk` + `fontsCss` and writes, with no network access.

/** The whole emitted file, from an ordered face list. Pure: no network, no
 *  filesystem. The url() is two hops because fonts.css lives in
 *  contracts/design-generated/ and the binaries stay in assets/ at the root --
 *  the design level moved under contracts/, the binaries did not. */
export function fontsCss(faces) {
  const header =
    `/* contracts/design-generated/fonts.css — self-hosted, CSP-clean webfonts.\n` +
    `   GENERATED by scripts/fetch-fonts.mjs; edit that, not this. Binaries live in\n` +
    `   assets/fonts/. Families match contracts/design-generated/typography.css\n` +
    `   (Archivo / Familjen Grotesk / Spline Sans Mono). */\n`;
  const rules = faces.map(({ family, weight, file }) =>
    `@font-face {\n` +
    `  font-family: '${family}';\n` +
    `  font-style: normal;\n` +
    `  font-weight: ${weight};\n` +
    `  font-display: swap;\n` +
    `  src: url('../../assets/fonts/${file}') format('woff2');\n` +
    `}`);
  return `${header}\n${rules.join('\n\n')}\n`;
}

/** The face list derived from what is on disk, for regenerating the CSS without
 *  re-downloading anything.
 *
 *  A declared weight with no binary is SKIPPED rather than refused, because
 *  families() hands every family the same weight list -- every fw-* token --
 *  and Google Fonts does not serve every weight for every family. Archivo has
 *  400-900; Familjen Grotesk and Spline Sans Mono have 400-700, and
 *  familjen-grotesk-800.woff2 has never existed. Demanding one would refuse the
 *  tree as it has always stood.
 *
 *  A family with NO face is a different matter and does throw: that is the
 *  silent-failure shape check:fonts exists to catch -- a --font-display naming
 *  a family with no @font-face behind it, falling through to system-ui with no
 *  error at all. */
export function facesFromDisk(root) {
  const present = new Set(readdirSync(join(root, 'assets', 'fonts')));
  const faces = [];
  for (const fam of families(root)) {
    const before = faces.length;
    for (const weight of fam.weights) {
      const file = `${fam.slug}-${weight}.woff2`;
      if (present.has(file)) faces.push({ family: fam.css, weight, file });
    }
    if (faces.length === before)
      throw new Error(`no assets/fonts/${fam.slug}-*.woff2 for "${fam.css}" — run bun scripts/fetch-fonts.mjs without --css-only`);
  }
  return faces;
}
