# scripts/build/arena/

| script | emits | why it exists |
| --- | --- | --- |
| `build-intro.ts` | one `<page>.generated.js` per module entry an `intro/` page declares | Bundles what those pages import so the browser never has to resolve it. Everything the bundle reaches is inlined and its types are stripped, which is what lets a page under `intro/` read `scripts/lib/` at all. |

This is the `arena` domain because it reads `scripts/lib/` and writes `intro/`, which belongs
to no framework layer and is the repository's own front matter: the pages that explain
Dravensoft's identity and Arena's fundamentals.

**Its output is tracked, and that is the whole reason the script exists.** The Claude Code
plugin is served from the git tag, where nothing runs a build, so a page there is served
exactly what the repository holds. Until this script, that meant every module an `intro/`
page imported had to be servable on its own, and the two under `scripts/lib/` it reaches,
`css-decls` and `token-preview`, could not be TypeScript: a browser strips no types
and `static-server.ts` declares no MIME for `.ts`. A bundle moves that requirement off the
source and onto one generated file. `.gitignore` ignores `frameworks/**` alone, so nothing
had to change for the output to be tracked; `check:generated` reads the `.generated.` infix
and finds it in the index.

**A page's module entry must be the bundle, never the source.** A page pointing back at its
own `.js` would serve whatever that source imports and undo the arrangement silently, so
`build-intro.ts` refuses to build such a page and `check:intro` refuses to pass one. The
entries are read out of the pages rather than listed in the script, so a page added for the
next major is covered the day it lands rather than the day somebody remembers a list.

`theme.js` and `density.js` are classic scripts, not modules, and import nothing; they are
served as they are and this script does not touch them. `intro/support.js` is generated by
`dc-runtime`, whose source is not in this repository, and `check:generated`'s `UNMARKED`
carries that reason.
