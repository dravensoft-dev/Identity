# scripts/check/arena/

The domain for a gate that reads two or more layers at once, or the repository root.

| gate | fails when |
| --- | --- |
| `check-all.mjs` | not a gate, but the runner: `GATES` is the registry, and `testStep()` is the **single authority** for how the test suite is invoked. Read the invocation there rather than reconstructing one; a narrowed run matching fewer files is indistinguishable from one matching all of them. |
| `check-docs.mjs` | a `.md` exceeds 60,000 characters, a `.md` punctuates its prose with an em dash, or a hand-written source carries a comment it is not allowed: `scripts/` and tests may carry one header of at most 10 lines, everything else none. `SIZE_EXEMPT` names the three documents exempt from the limit by charter and `PROSE_EXEMPT` the one tree exempt from the punctuation rule, each with its reason. Both rules read by lexing, so a `//` inside a string is never mistaken for a comment and an em dash inside a fence or a code span is the document quoting code; a `.generated.` file is skipped unread. It also holds the branch boundary, over every consumer document: a `.prompt.md` anywhere, and a `SKILL.md` under `frameworks/`. Citing a path under `scripts/`, a `README.md` under `contracts/` or `frameworks/`, or `frameworks/PACKAGING.md` sends a reader somewhere the router promised they would not have to go. `CONTRIBUTOR_PATHS` carries a reason per shape, and `BRANCH_SWITCH` carries the single carve-out: the root `SKILL.md`, which names the contributor branch because naming it is how it sends a contributor away. Nothing below it has anybody left to redirect, so a document there needing an exception is a rule stated on the wrong branch. |
| `check-generated.mjs` | a file whose header says a script writes it does not say so in its name, or a `.generated.` file is neither tracked nor covered by a reason-carrying ignore entry. Both directions fail silently otherwise: an unnamed output is read as hand-written, and an ignored payload file ships a tag whose `intro/styles.css` `@import`s resolve to nothing. |
| `check-skills.mjs` | `frameworks/SKILL.md` or a layer's own `SKILL.md` stops matching a fresh emit, or one falls out of the git index. The index tree is tracked rather than built, because the plugin is served from the git tag where nothing runs a build, so a stale copy is a wrong answer handed to every reader of that tag with every other gate green. Tracking is this gate's to assert because `check:generated` scans no `.md`. Fails on an empty declaration too, rather than comparing an index of nothing against an index of nothing. |
| `check-prompts.mjs` | a `.prompt.md` carries no `@api` region, or one that does not match a fresh emit from `contracts/api/components/<Name>.json`. A prompt is where a consumer stops reading, so the members have to be stated there; a hand-typed table would be a second copy of the contract that nothing holds, and the fix for a wrong cell is always the contract. Whether a component is contracted at all is `check:api`'s question, so an uncontracted one is counted rather than failed. |
| `check-api.mjs` | a layer's implementation diverges from `contracts/api/components/<Name>.json`. **No exception map at all**, deliberately: a contract forbids divergence, so it has nowhere for a second opinion to live. |
| `check-playgrounds.mjs` | a fixture under `frameworks/demos/` stops holding against the contract it seeds: a seed the contract does not declare, a value of the wrong type, an enum value outside its declared set, a required member or slot the fixture leaves empty, a bind naming something that is not an event or writing a payload into a member that cannot hold it, or a host that does not mark exactly one place for the component under test. Type-checking a seed is the whole point: a component drawn from a bad seed still draws, so the page renders and lies while every other gate stays green. It also holds the citation rule, that no `.prompt.md` and no layer `README.md` names a path or a page filename that nothing under `frameworks/` carries; a sibling cited by its bare name is the one shape a rename rewrites in every import and in no sentence. Last, it loads all 110 emitted pages in a real browser and fails one that mounts nothing, draws no panel, draws an empty stage or says anything on the console: every other check here compares emitted SOURCE, and a source that compiles can still throw on its first render. That half needs a browser, on the same terms as the two gates below, and it runs only once the portable half is clean, so a fixture defect still reports on a machine with none. |
| `check-icons.mjs` | a `ph-` class name in the tree is not a Phosphor glyph, or is a glyph the weight beside it does not carry. Nine contracts take an icon as a string and nothing checked the string: a typo renders an empty box, with no error and no failing gate. The truth is read out of the installed `@phosphor-icons/web` rather than typed here, because a list of 1500 names ages the first time the package does, and finding no stylesheet is an explicit failure rather than a pass over nothing. `SCANNED_ROOTS` is the scope and `EXEMPT` is empty on purpose: a name Phosphor does not have is a typo rather than a case. |
| `check-behaviour.mjs` | a component declares no `<Name>.behaviour.json`, names a pattern or requirement that does not exist, or the two layers disagree without saying why. A green run is a **coverage** claim, never an accessibility one. |
| `check-compliance.mjs` | a coverage claim in `COVERED` is stale: a suite that no longer exists, or one whose layer key does not match the `SUITE_DIRS` tree it was found under. Coverage is partial by design; the gate never demands totality, only that every claim is true. |
| `check-contracts.mjs` | `contracts/` stops holding the shape `contracts/README.md` describes: a stray file in a level, a level missing its normative document, an undeclared inner directory, or a fourth directory beside the three. `SHAPE` is the declaration, and `design` is the one level whose normative statement is two documents, `README.md` for what a value means and `TokenTypes.md` for the shape it arrives in. It is `check-structure.mjs`'s analogue for `contracts/`. |
| `check-structure.mjs` | a component is declared in two categories, sits in a category `frameworks/Components.json` assigns elsewhere, is named by no declaration, or is present in no layer. It says nothing about whether the category is the **right** one. |
| `check-script-tokens.mjs` | a `Tokens.generated.*` module disagrees with the DTCG source or the CSS, a `script: true` flag is orphaned, or `CatSlot` stops being exactly `1..catSlots` in order. |
| `check-duplicate-constants.mjs` | the same module-level named numeric constant is declared in **both** framework layers. Generated output is out of scope: a file a script writes into every layer is one declaration rather than two, it cannot drift between them, and the gate holding it to its single source is the one that would notice if it did. |
| `check-dimension-literals.mjs` | a framework layer writes a bare literal in a property the token layer governs. `EXEMPT` and `PASSTHROUGH` are asserted by name in the paired suite, so changing either is a change to both. |
| `check-manifest-states.mjs` | a manifest slot carries a `hover:`/`focus:` state modifier no contract it covers declares in `affordances`, or a component that draws by hand implements a state its contract does not declare. Both halves read the contract and neither reads the other layer; both run one way only, because a declared affordance a layer leaves to the child it composes is not a divergence. A layer that realises an affordance by rendering the manifest's own class has no answer of its own to give, and that is now both layers wherever a component renders its recipe, so the react half reads `HAND_DRAWN` rather than every component: an empty `HAND_DRAWN`, or one of its members never opened, is a failure rather than a clean pass. `MANIFEST_COVERS` and `HAND_DRAWN` both live in `scripts/lib/tailwind/manifest-surfaces.mjs`, because two gates read them and either owning them would make the other import in a cycle. This checks **states only**, and nothing about colors, sizes or slot structure. |
| `check-appearance.mjs` | a component in scope does not render the manifest that draws its surface, in either layer, or the React layer types a style property out by hand. The literal half's rule needs no list of governed properties, because a style object holds nothing else: **a property whose every branch is a literal belongs in the manifest, and one that reads an identifier or an interpolation is a runtime computation and stays**. That is what tells `CalendarEvent`'s surviving `color-mix` from a `background: 'var(--crimson)'`. It reads inline `style={{…}}`, a constant annotated `React.CSSProperties`, and an object returned from a function annotated the same, skipping `dist/`. `EXEMPT` is empty, and that emptiness is the claim. Three blind spots are declared rather than closed: a style object assembled with `Object.assign` or a computed spread, a literal reached through an unannotated lookup table, and Angular's `[style.x]="<literal>"`, which is the blind spot `check-dimension-literals.mjs` already declares in its own header. |
| `check-layer-independence.mjs` | a file under `frameworks/<A>` names layer B or one of B's source files, by import or in prose. `ALLOWED` carries the one edge, Angular consuming a Tailwind manifest, and `EXEMPT` the individual cases, both asserted by name in the paired suite. A citation is caught in prose as well as in an import, because prose is where such a coupling mostly lives. |
| `check-focus-trap.mjs` | a modal panel's interior lets Tab escape, in any layer that binds `dialog-modal`. Drives real Chromium over each declared page and presses a real Tab, which is the one thing a happy-dom suite cannot prove; without a browser it cannot run, which the declared strict setting makes a failure rather than a skip. Each page opens its panel from its own fixture, so no walk depends on finding a button by its copy: a page whose wording moved would otherwise be walked with nothing open and report a trap that holds. |
| `check-card-viewports.mjs` | a page's rendered content over-runs the `@dsCard` viewport it declares, in either axis, because the card is cropped to it and the overflow is lost silently. Needs a headless browser, on the same terms. |
| `check-shared-arithmetic.mjs` | two copies of one module, authored at the same path in both layers, stop agreeing on a function they both export. Six modules are written twice and nothing held any of them together: `check:duplicate-constants` reads module-level **numbers**, so an exported function is invisible to it, and a calendar whose layers disagree by arithmetic draws two different schedules from one set of events. Bodies are compared with their whitespace normalised, so a signature may differ where a body may not, which is the whole distinction: `DIVERGENT` carries the ones that genuinely differ, each saying what the two do the same and what they spell differently, and **fails on an entry whose two bodies have since been reconciled**. |
| `check-packages.mjs` | the `arena-theme` CLI that ships inside both npm packages stops emitting what Style Dictionary emits, or an assembled `dist/` is not registry-standard: a version out of step with `plugin.json`, an `exports` target that was never emitted, an install script, a missing README, or Phosphor bundled rather than declared a peer. Two emitters exist for the palette, so something has to hold them together; a zero-declaration comparison is an explicit failure. `dist/` is git-ignored, so the manifest half is skipped on a fresh clone and the run says so. |
| `check-release.mjs` | any release surface disagrees with `.claude-plugin/plugin.json`, above all when the `plugin.json` **at the pinned tag** hands out a different version than the marketplace advertises. Forgetting the `ref` fails silently: the update is never offered and nothing errors. Run by path, with no npm script. |

## What `check-dimension-literals.mjs` reaches

A value passes when it is `var(--token)`, a `calc()`/`min()`/`max()`/`clamp()` over one, zero,
or a unit the token layer does not model: `%`, `ch`, `fr`, the viewport units and the angle
units, since DTCG admits only `px` and `rem` in a dimension, plus `s` and `ms`, which this gate
alone tolerates. **The same three shapes are what a Tailwind bracket may hold, and the two gates
share the same unmodelled-unit list**, but they are not one list: this gate additionally
tolerates `s`/`ms` and the bracket gate does not, because `--dur-*` and `--loop-*` model
duration.

The scan reaches four kinds of site: a JS declaration, a template literal's interpolation, CSS
injected as a string, and an SVG presentation attribute in `prop="value"` form. An expression
binding, `r={hover ? 5 : 4}`, is outside all of them. A literal reached through an
intermediate local variable is still caught, but only when that identifier is used bare (no
member access, no call, no arithmetic) at the governed site.

It scans `.jsx`, `.ts` and `.tsx` under `frameworks/`, not `.html`, and nothing under `intro/`,
so those pages stay clean only because they are tokenized by hand. The `*.card.html` specimens
under `frameworks/tailwind/` are the one family of unscanned pages that stays clean
structurally: every class they render comes from the manifest through `classesFor()`.

**Two blind spots are known and neither is fixed**: a kebab-case SVG attribute, and Angular's
`[style.x]` binding form, which sits outside all four scanners. This is why the three SVG
charts write their static styling as camelCase `[style]` **objects**: in that shape
`strokeWidth` and `fontSize` are judged as themselves, which is strictly more coverage than an
attribute.

A handful of sites are exempt by name with a reason each: read `EXEMPT` for the current set
rather than a count. A stale exemption fails the gate itself, and a change to `EXEMPT` or
`PASSTHROUGH` is a change to `check-dimension-literals.test.mjs` too, since that suite asserts
on both maps by name.

Every `X.test.mjs` beside a gate covers that gate. Two suites here name no gate:
`browser-modules.test.mjs` covers the `intro/` runtime modules, and
`components-categories.test.mjs` covers `frameworks/Components.json`, and both are claims about
the repository root, which is what makes them `arena`.
